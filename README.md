# FitZone – Fitness Club Website 🏋️

FitZone is a responsive fitness club website designed to provide users with an easy way to explore gym facilities, discover membership plans, and connect with the fitness center. The website features a clean design with interactive elements and mobile-friendly navigation.

## 🌟 Features

- **Home Page** – Introduction to FitZone and its fitness services.
- **Gallery Section** – Explore gym facilities and training environments through a horizontal image gallery.
- **Packages Page** – Browse different membership plans with pricing and features.
- **Search & Filter** – Search packages and filter them by duration and price.
- **Contact Page** – Contact form with built-in HTML validation and JavaScript interactions.
- **Responsive Navigation** – Mobile-friendly sidebar navigation.
- **Interactive Elements** – Hover effects, package selection and dynamic filtering.

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- Font Awesome Icons

## 🎯 Project Objective

The objective of this project is to develop a responsive fitness club website while gaining practical experience in front-end web development, responsive design, and JavaScript functionality.

## 🚀 Key Learnings

- Creating responsive layouts using Tailwind CSS.
- Working with Flexbox and CSS Grid.
- Implementing DOM manipulation using JavaScript.
- Handling click and submit events.
- Applying search and filtering functionality.
- Implementing HTML form validation.
- Creating interactive and mobile-friendly navigation.
